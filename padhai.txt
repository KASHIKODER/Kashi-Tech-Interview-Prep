---> class ke naam jesa hi class hota hai

---> overloading supported hai (multiple constructor ek class mai ho sakte hain)

constructor ke 4 type hote hain :-
1. Default constructor 
2. parameterized constructor
3. private constructor
4. copy constructor

constructor keypoints :-
1) constructor is called automatically when class is created using the new keyword.
2) if you don't create any constructor , java provided default constructor .
3) constructor can not be inherited but can be invoked via using super() keyword.

code :- 
class Student{ ---> class
    int id; ----> blueprint
    string name;
    Student(){ ----> constructor
        id = 101;
        name = John;
        System.out.pritln("Constructor called");
    }
}
public class Main{
    public static void main(string[] args){
        Student s = new Student();  ---> constuctor called / object created
    }
}
